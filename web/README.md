# Self-paced web edition

[first-day-with-ai.html](first-day-with-ai.html) is the whole course as one
self-paced page. It has eight chapters, about six hours, and breaks marked
between chapters, all built from the modules, activities, and handouts in this
repo.

- **Published copy:** https://claude.ai/artifact/W7eTiSB1jxrznYpich4rH2
  - It's private until shared from the page's Share menu.
  - Opened there, learners can run the plain and improved prompts side by side
    through Claude on their own Claude account, and get coach feedback.
- **Opened locally from this file:** live practice is off, and every prompt
  has a Copy button for use in the agency's approved tool. Everything else
  works: the activities, checks, builders, and saved progress.
- **Progress** is kept in the learner's browser only.
- **Practice data:** only the fictional City of Brookfall files; the page tells
  learners so throughout.

If you edit the course content, update the page to match. It holds its own
copy of the Brookfall files and prompts.
