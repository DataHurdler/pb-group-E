## Research worth knowing about

| Source | Finding |
| --- | --- |
| [The Prompt Report (Schulhoff et al., 2024)](https://arxiv.org/abs/2406.06608) | A survey cataloguing 58 text prompting techniques; the field's map |
| [Prompting Science Report 4 (Wharton, 2025)](https://arxiv.org/abs/2512.05858) | Expert personas ("You are an expert…") don't reliably improve accuracy |
| [Prompting Science Report 3 (Wharton, 2025)](https://arxiv.org/abs/2508.00614) | Tipping or threatening the model has no reliable effect |
| [Prompting Science Report 2 (Wharton, 2025)](https://arxiv.org/abs/2506.07142) | Chain-of-thought prompts add little for reasoning models, and add time |
| [Lost in the Middle (Liu et al., 2023)](https://arxiv.org/abs/2307.03172) | Models use the start and end of long inputs better than the middle |
| [Sycophancy in language models (Sharma et al., 2023)](https://arxiv.org/abs/2310.13548) | Models tend to tell you what you seem to want to hear |
| [Judging LLM-as-a-judge (Zheng et al., 2023)](https://arxiv.org/abs/2306.05685) | AI graders favour longer answers, the first answer shown, and their own output |
