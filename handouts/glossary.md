# Plain-English Glossary

| Term | Meaning |
| --- | --- |
| **AI assistant / chatbot** | A tool you type to and that types back: ChatGPT, Microsoft Copilot, Claude, Gemini, and others |
| **Large language model (LLM)** | The engine inside the assistant. It has learned patterns from a very large amount of text and writes by predicting what words should come next |
| **Prompt** | Everything you give the model: your instructions, any pasted text or files, and the conversation so far |
| **Conversation / chat / thread** | One continuous exchange. The model "remembers" only what's in the current conversation, unless a memory feature is turned on |
| **Context window** | How much text the model can consider at once. Very long pastes may be cut off or partly ignored |
| **Hallucination / fabrication** | Confident, fluent output that is false: an invented fact, quote, number, or citation |
| **Grounding** | Giving the model a source and telling it to answer only from that source |
| **Examples (few-shot prompting)** | Showing the model one or more samples of what you want so it copies the pattern |
| **Prompt chaining** | Splitting a task into steps and running them one after another, checking each step |
| **Custom instructions / system prompt** | Standing instructions that apply to every chat, set in the tool's settings |
| **Sycophancy** | The model's tendency to agree with you or praise your idea. Ask for criticism explicitly if you want it |
| **Training cutoff** | The date after which the model learned nothing new. Without web search, it doesn't know recent events or policy changes |
| **Reasoning model** | A model that works through a problem before answering. Slower, and often better on multi-step tasks |
| **Approved tool** | An AI product your agency has reviewed and licensed for work use, with specific rules about what data it may handle |
