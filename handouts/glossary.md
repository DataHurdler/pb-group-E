# Plain-English Glossary

Status: ready

| Term | Meaning |
| --- | --- |
| **AI assistant / chatbot** | A tool you type to and that types back: Microsoft Copilot, ChatGPT, Claude, Gemini, and others |
| **Large language model (LLM)** | The engine inside the assistant. It has learned patterns from a very large amount of text and writes by predicting what should come next |
| **Prompt** | What *you* write and send: your instructions and any material you paste with them |
| **Context** | *Everything* the model can see when it answers: your prompt, plus the conversation so far, uploaded files, search results, and any custom instructions or memory. Your prompt is only part of it |
| **Conversation / chat / thread** | One continuous exchange. The model "remembers" only what's in the current conversation, unless a memory feature is turned on |
| **Context window** | How much text the model can consider at once. Very long pastes may be cut off or partly ignored |
| **Context rot / drift** | Long conversations get less reliable: early instructions fade and old turns steer new answers. Start fresh and carry over what matters |
| **Token** | The unit the model reads and writes in, roughly three-quarters of a word. Limits and costs are counted in tokens |
| **Training cutoff** | The date after which the model learned nothing new. Without web search it doesn't know recent events or policy changes |
| **Confabulation / hallucination** | Confident, fluent output that is false: an invented fact, quote, number, or citation |
| **Sycophancy** | The model's tendency to agree with you or praise your idea. Ask for criticism explicitly if you want it |
| **Automation bias** | The human tendency to trust a machine's output too much, especially when it looks polished |
| **Grounding** | Giving the model a source and telling it to answer only from that source |
| **Delimiters** | Markers such as `<notes> … </notes>` that show where pasted material starts and ends |
| **Prompt injection** | Text inside a document, email, or web page written to act as an instruction to the AI |
| **Few-shot prompting** | Showing the model one or more examples of what you want so it copies the pattern |
| **Prompt chaining** | Splitting a task into steps and running them one after another, checking each step |
| **Reasoning / thinking mode** | A setting in which the model works through a problem before answering. Slower, and often better on multi-step tasks |
| **Web search / deep research** | Modes in which the tool looks things up online, or runs a multi-step research process, before answering |
| **Meta-prompting** | Asking the AI to write or improve a prompt |
| **Custom instructions / projects / Gems / agents** | Saved standing instructions (and sometimes files) that apply to every chat in that setup |
| **AI-as-judge** | Using an AI to grade AI output. Useful for a first pass; biased toward longer answers and its own writing |
| **High-impact AI** | In federal policy, AI whose output is a principal basis for decisions with significant effects on people's rights, benefits, or safety |
| **Approved tool** | An AI product your agency has reviewed and licensed for work use, with specific rules about what data it may handle |
| **Slot** | One of the six parts of a well-structured prompt: Task, Context, Audience, Constraints, Format, Examples |
| **Traffic light** | This course's Green / Yellow / Red rule for what may go into a prompt |
| **Quote first** | Asking the model to quote the source passage it relies on before answering, so you can check it |
| **Flag line** | An instruction that makes the model mark gaps instead of guessing: "If it isn't stated, write NOT STATED" |
| **Checkable criteria** | Pass/fail tests for an output that two people would apply the same way |
| **Test input / probe** | A second, harder input to try a prompt on; a probe is a question the source can't answer, to see whether the model admits it |
| **Template / brackets** | A saved prompt with `[BRACKETS]` for the parts that change each time |
| **Cold test** | Someone else running your template without asking you anything |
| **CJIS** | Criminal Justice Information Services: FBI rules for handling criminal-justice data |
| **HIPAA** | The federal health-privacy law covering protected health information |
| **FTI** | Federal Tax Information, protected under IRS Publication 1075 |
| **GCC** | Microsoft's Government Community Cloud, a version of Microsoft 365 for U.S. government customers |
