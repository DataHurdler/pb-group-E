# Pre/Post Check

Status: ready
Used: Module 00 (8:41) and Module 07 (3:45) · 5 min · Individual, anonymous
Objectives: LO1 (Q1–3), SU (Q4–5), LO2 (Q6), LO3 (Q7–8), LO4 (Q9), LO5 (Q10)

The same ten questions morning and afternoon. Each participant picks a
neutral code word (a favourite food plus a number) and writes it on both copies,
so the two can be paired without names. Don't use codes built from personal
details.

Every question has an **"I don't know yet"** option. Encourage it in the
morning; it's more honest than a guess, and it makes the gain measurable.

Ungraded unless the host agency attaches credit. Answers, and what each wrong
answer suggests, are in
[../instructor/answer-keys.md](../instructor/answer-keys.md#prepost-check).
