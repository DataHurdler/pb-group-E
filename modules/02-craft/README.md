# 02 The CRAFT Prompt

Status: ready
Time: 10:45–12:00 (75 min) · Talk 18 / do 57
Outcomes: LO3 (LO2 reinforced)

## Purpose

Give first-time users one checklist (Context, Request, Audience, Format, Test)
that fixes most weak prompts, practise it on shared tasks, and get a version 1
prompt for each participant's own job.

## By the end of this block, participants can…

- Name the five parts of CRAFT and spot which are missing from a weak prompt
- Rewrite a weak prompt with all five parts and get noticeably better output
- Write a first CRAFT prompt for a recurring task of their own, using stand-in
  data

## Live build (12 min)

Use [hydrant-notice.md](../../materials/data/hydrant-notice.md). New chat each
time. Ask the room "what would you add?" before each step.

| Step | Add | What the room should notice |
| --- | --- | --- |
| 1 | **R** only: "Rewrite this notice in plain language." + paste | Better, but still long, still formal |
| 2 | + **A**: residents, on phones, some with limited English, 6th-grade level | Shorter words, friendlier |
| 3 | + **F**: under 150 words, headline + three sections, keep every date, time, and number | Scannable; facts preserved |
| 4 | + **C**: "I work in Public Works…", source in `<notice>` tags | Small change here, since the notice carried most of the context. Say so: Context matters most when there's no source to paste |
| 5 | + **T**: use only the notice; list what you left out | It tells you it dropped the usage-credit detail, or it keeps it. Either way you know |

Points to make while building:

- **Request:** one main job, starting with a verb. Two jobs, two prompts.
- **Audience** is the most skipped part, and the one that changes the most for
  public-facing writing.
- **Format:** say what to *keep exactly* (dates, numbers, contacts) as well as
  the shape.
- **Test:** it costs one sentence and turns invisible omissions into a list you
  can check.
- **Tags or quotes around pasted text** (`<notice> … </notice>`) keep the
  model from confusing your instructions with the material.
- **Iterate in the chat** for small fixes ("shorter", "warmer"). **Start a new
  chat** when you've changed the prompt itself, so old turns don't steer it.

## Check for understanding

While circulating in 2A, ask a pair to point to the **Audience** part of their
rewrite. If they can't, they've written a longer Request, not a CRAFT prompt.

## Common problems

| Problem | Response |
| --- | --- |
| CRAFT prompt is a wall of text | Fine for now. Length isn't the problem; vagueness is. Suggest line breaks per letter |
| Participant can't think of a task for 2B | Offer the list on the sheet; "the email you answer most often" works for almost everyone |
| Own task involves people decisions | Redirect to the writing part of it: "the letter explaining the decision", not the decision |
| Someone pastes real data in 2B | Quietly stop them, help make a stand-in; don't make an example of them |

## Instructor notes

- Expect Context and Format to win the tally; Audience usually wins for the
  hydrant notice. Either is a good teaching moment.
- 2B must not be cut. It's the seed for the capstone, and the only time before
  3:00 that participants work on their own job.
