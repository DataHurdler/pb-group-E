# 00 Welcome and First Prompt

Status: ready
Time: 9:00–9:30 (30 min) · Talk 12 / do 18
Outcomes: sets up all; no outcome checked here

## Purpose

Show in the first four minutes that how you ask changes what you get, settle
nerves, measure the starting point, and get every participant signed in and
past their first prompt before any theory.

## Timed outline

| Min | Segment | Format | What happens |
| --- | --- | --- | --- |
| 0–4 | Hook | Instructor demo | Run the weak and CRAFT notice prompts live (below). Don't explain why yet: "By lunch you'll be able to say exactly why the second one worked." |
| 4–12 | Introductions | Tables | Each person: name, where they work, one task that eats their week. Then the room shows its AI experience with fingers: 0 never, 1 tried it, 2 sometimes, 3 weekly |
| 12–17 | Pre-check | Individual | [Pre/post check](../../assessment/pre-post-check.md), 8 questions, ungraded, anonymous code |
| 17–22 | The day | Instructor | Outcomes in plain words, agenda, ground rules (below) |
| 22–30 | Sign in, first prompt | Individual, helpers circulate | Sign in to the approved tool, find "new chat", run the first prompt (below). Anyone blocked joins a neighbour |

## Hook demo

Run in two separate new chats, on the projector.

**Weak:**
> Write a notice about water flushing.

**CRAFT:** the assembled prompt in
[craft-cheat-sheet.md](../../handouts/craft-cheat-sheet.md), with
[hydrant-notice.md](../../materials/data/hydrant-notice.md) pasted in.

What usually happens: the weak version invents dates, areas, and a phone number,
and sounds completely official. The CRAFT version keeps the real facts. Point at
one invented detail and move on; Module 01 comes back to it.

## Ground rules (say them, and leave the slide up)

1. **Fictional data only today.** Everything you need is in the Brookfall
   folder. Even your own-task practice uses made-up details. This isn't
   paranoia; it's the habit we want on Monday.
2. **New task, new chat.**
3. **Skeptics welcome.** If you leave knowing exactly when *not* to use AI,
   that's a success.
4. **Parking lot.** Policy and "what about tool X" questions go on the sheet;
   we'll come back to them.
5. **You'll keep what you make.** Nothing is collected without asking.

## First prompt

> In three sentences, explain what you are and three things you can't do well,
> for a city employee who has never used an AI assistant.

Then: "Ask it a follow-up question about something it said." This gets everyone
through the mechanics of a two-turn conversation.

## Check for understanding

By 9:30 every participant has a working chat on screen, either their own or
a neighbour's. Count heads; don't move on with anyone stuck at sign-in without a
partner.

## Common problems

| Problem | Response |
| --- | --- |
| Can't sign in / account not provisioned | Pair with a neighbour now; helper troubleshoots during Module 01 activity. See [setup-and-tech.md](../../instructor/setup-and-tech.md) |
| Tool blocked on agency network | Pre-tested fallback in setup notes; pair otherwise |
| "Is this going to replace my job?" | Acknowledge, don't debate: "Fair question, and it goes on the parking lot. Today is about you being the one who uses it well." |
| Someone already expert | Ask them to be a table helper; give them the stretch tasks |

## Instructor notes

- The pre-check must come before the day overview, or the overview teaches the
  answers.
- If sign-in eats more than 8 minutes, take the time from 01's first lecture,
  not from its activities.
