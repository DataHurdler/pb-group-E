# 00 Welcome and First Prompt

Status: ready
Time: 8:30–9:00 (30 min) · Talk 11 / do 19
Objectives: sets up all; nothing checked here

## Purpose

Show in four minutes that how you ask changes what you get, measure the
starting point, start each participant's own-task thread, and get everyone
signed in to the right account before any theory.

## Timed outline

| Min | Segment | Format | What happens |
| --- | --- | --- | --- |
| 0–4 | Hook | Instructor demo | Run the weak and the structured notice prompts live (below). Don't explain yet: "By lunch you'll be able to say exactly why the second one worked." |
| 4–11 | Introductions | Tables | Name, where you work, **one task that eats your week** (write it on an index card and keep it, because it becomes your capstone). Then fingers for AI experience: 0 never, 1 tried it, 2 sometimes, 3 weekly at work |
| 11–16 | Pre-check | Individual | [Pre/post check](../../assessment/pre-post-check.md), 10 questions, anonymous code |

| 21–30 | Sign in, first prompt | Individual, helpers circulate | Sign in to the approved tool **with the work account**, find "new chat", run the first prompt (below). 2-minute instructor walkthrough of the screen: new chat, the mode picker, where uploads and search are |

## Hook demo

Two separate new chats, on the projector.

**Weak:**
> Write a notice about water flushing.

**Structured:** the assembled prompt in
[prompt-anatomy-cheat-sheet.md](../../handouts/prompt-anatomy-cheat-sheet.md),
with [hydrant-notice.md](../../materials/data/hydrant-notice.md) pasted in.

What usually happens: the weak version invents dates, areas, and a phone number
in a perfectly official voice. The structured version keeps the real facts.
Point at one invented detail and move on; Module 01 explains it. Never promise
the room a particular result. If the weak one comes out fine, ask: "Where did
it get those dates?"

## Ground rules (say them; leave the slide up)

1. **Fictional data only today.** Everything is in the Brookfall folder. Even
   your own-task practice uses made-up details.
2. **Work account, not personal.** Check the account name in the corner now.
3. **New task, new chat.**
4. **Skeptics welcome.** Knowing exactly when *not* to use AI counts as success.
5. **Parking lot** for policy and "what about tool X" questions.
6. **You keep what you make.** Nothing is collected without asking.

## First prompt

> In three sentences, explain what you are and three things you can't do
> well, for a city employee who has never used an AI assistant at work.

Then: "Ask it a follow-up question about something it said." Everyone gets
through a two-turn conversation before 9:00.

## Check for understanding

By 9:00 every participant has a working chat in a work account, their own or
a neighbour's. Count heads.

## Common problems

| Problem | Response |
| --- | --- |
| Can't sign in / not provisioned | Pair with a neighbour now; helper fixes it during the Module 01 activity. See [setup-and-tech.md](../../instructor/setup-and-tech.md) |
| Signed in with a personal account | Sign out, sign in with the work account. If they don't have one, pair them |
| "Is this going to replace my job?" | Acknowledge, don't debate: "Fair question, and it goes on the parking lot. Today is about you being the one who uses it well." |
| Someone is already expert | Make them a table helper; point them to the stretch tasks |

## Instructor notes

- The pre-check comes before the day overview, or the overview teaches the
  answers.
- If sign-in eats more than 9 minutes, take the time from Module 01's poke-the-model
  segment, not from its activity.
