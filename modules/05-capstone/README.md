# 05 Capstone: Your Reusable Prompt

Status: ready
Time: 15:00–15:40 (40 min) · Talk 4 / do 36
Outcomes: LO3, LO4, LO5 (LO2 reinforced)

## Purpose

Each participant leaves with a tested, reusable prompt template for a real
recurring task from their own job, one a coworker can run without help.

## By the end of this block, participants can…

- Build a template that combines CRAFT, a fitting technique, brackets for the
  parts that change, and a human-review step
- Test someone else's template and give specific feedback
- Revise their own template from test results

## Materials

- Activity 5 sheet, [capstone rubric](../../assessment/capstone-rubric.md),
  [prompt library](../../handouts/prompt-library.md)
- Participants' saved 2B prompts

## Check for understanding

The partner test *is* the check. Watch for partners asking the author questions.
Each question is a missing bracket or missing context in the template. Point
that out; it's the most useful feedback of the day.

## Common problems

| Problem | Response |
| --- | --- |
| Lost the 2B prompt | Start from the closest prompt-library template; that's what it's for |
| Template is too specific to reuse | "What would change next month?" Each answer becomes a bracket |
| Partner test is just "looks good!" | Hand them the rubric and ask for a score on each row |
| Uneven numbers | One trio: A tests B, B tests C, C tests A |

## Instructor notes

- Collect templates only with permission, for example to share an anonymized
  set in the follow-up email.
- If running late, shorten Build to 12 minutes, never the partner test.
