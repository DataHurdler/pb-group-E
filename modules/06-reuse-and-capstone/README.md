# 06 Reuse, Efficiency, and Capstone

Status: ready
Time: 3:05–3:45 (40 min) · Talk 8 / do 32
Objectives: LO5 · Use prompting strategies that improve efficiency while maintaining output quality. (LO2–LO4, SU checked in the capstone)

## Purpose

Turn a prompt that worked once into a tool that keeps saving time without
losing quality, and decide where AI doesn't belong in a task. Each participant
leaves with a tested template for their own job that a colleague can run
without asking them anything.

## By the end of this block, participants can…

- Turn a working prompt into a template with brackets and a use/don't-use header
- Write a prompt-library entry that says what good output looks like and where
  the prompt goes wrong
- Explain when saved setups (custom instructions, projects, Gems, agents) help,
  and their risks
- Turn a long conversation into one reusable prompt
- Decide which steps of a task AI should do, help with, or stay out of
- Cold-test a colleague's template and give specific feedback

## Talking points (8 min)

1. **Reuse beats rewriting.** A prompt that worked is an asset. Replace
   everything that changes with `[BRACKETS]`, and put a header on top:
   `USE THIS FOR / DON'T USE THIS FOR / CHECK BEFORE USING`.
2. **A library entry has four parts:** what it's for; the prompt; what good
   output looks like; where it goes wrong. The last part is the one people
   skip, and it's the one that saves the next person. See
   [prompt-library.md](../../handouts/prompt-library.md).
3. **Saved setups.** Custom instructions, projects, Gems, Copilot agents, and
   saved prompts apply standing instructions (and sometimes files) to every
   chat. Great for a task you do weekly. Three cautions: check that your agency
   allows the feature; the setup is invisible to anyone reading the output; and
   memory can carry old context into new work. *Building an AI Agent* goes
   further: an agent's instructions are a prompt.
4. **Let the AI write the first draft of the prompt.** At the end of a
   conversation that finally worked: *"Turn this conversation into a single
   prompt that would get the final result in one go. Use [BRACKETS] for the
   parts that change."* Or: *"Here's my prompt. What's ambiguous or missing?"*
   Then trim it, because generated prompts are usually bloated, and test it.
5. **A fresh chat beats arguing with a drifted one.** After two corrections
   that don't stick, start over with a better prompt.
6. **Count the checking time.** Time saved is drafting time minus checking
   time. "Saves 20 minutes, needs 15 to check" saves 5.
7. **When not to use AI:**
   - checking it would take longer than doing it;
   - the data can't go in the box;
   - a mistake would be costly *and* hard to spot;
   - it's a decision about a person;
   - the point is that *you* did it: a condolence note, your own evaluation.

   Map your task's steps: **AI does · AI helps, I decide · Me only.**

## Check for understanding

The cold partner test is the check. The number of questions the partner wrote
down is the clearest single measure of reusability. Zero is the goal.

## Common problems

| Problem | Response |
| --- | --- |
| Lost the 03b prompt | Start from the closest library entry; that's what it's for |
| Template too specific to reuse | "What would change next month?" Each answer becomes a bracket |
| Partner says "looks good!" | Hand them the rubric and ask for a score on every row |
| Odd numbers | One trio: A tests B, B tests C, C tests A |
