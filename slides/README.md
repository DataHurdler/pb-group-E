# Slides

One deck for the whole day: [course-day.qmd](course-day.qmd), rendered to a
single self-contained [course-day.html](course-day.html) that works offline.

- **Present:** open the HTML in a browser. `F` full screen, `S` speaker notes,
  `Esc` slide overview.
- **Edit:** change the `.qmd`, then `quarto render slides/course-day.qmd`.
- **Before the day:** replace every `[BRACKETED]` placeholder (Wi-Fi, approved
  tool, policy, records officer, feedback link) and re-render.
- **Print / PDF:** open the HTML with `?print-pdf` appended to the URL and print
  from the browser.

Each module's section starts with a title slide carrying its clock time. Speaker
notes hold the facilitation cues; the full talking points are in each module's
README.
