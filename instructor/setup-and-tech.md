# Setup and Technology

The course is tool-neutral. Everything tool-specific lives on this page, so
it's the only page to refresh when interfaces change. **Re-check the details
below in the actual tool the week before.** AI products change their
interfaces often.

## What each participant needs

- A laptop (a phone works in a pinch, but pasting files is painful)
- A signed-in account on an **agency-approved** AI tool, tested before the day
- Access to the Brookfall files: shared drive, short link, or USB

## Tool notes

| Tool | Starting a fresh chat | Worth knowing for this course |
| --- | --- | --- |
| Microsoft Copilot (work account) | "New chat" | Many agencies approve this first. Confirm participants are signed in with their **work** account, not a personal one; the data protections differ |
| ChatGPT | "New chat" | If participants use personal accounts, a temporary chat or memory-off setting keeps practice sessions from carrying over. Free tiers may limit message volume; long days can hit the cap |
| Claude | "New chat" | Handles long pasted documents well |
| Gemini | "New chat" | Workspace accounts and personal accounts have different data terms |

For any tool, before the day:

- [ ] Can you paste a one-page document and get a reply?
- [ ] Does the agency network allow it (no proxy block)?
- [ ] Is there a usage cap a participant could hit in six hours of practice?
- [ ] Does it have memory or custom-instruction features on by default?
      Decide whether to have participants turn them off for the day

## Fallbacks

| Problem | Fallback |
| --- | --- |
| A few participants can't sign in | Pair them with a neighbour; one types, both decide |
| The tool is blocked on venue Wi-Fi | A pre-tested hotspot for the instructor demo; participants on their own approved devices or in pairs |
| The tool is down for everyone | Run activities from the pre-captured screenshots; participants write and critique prompts on paper, then try them that evening. Rare, and worth having a plan for |
| A participant hits a usage cap | Pair them for the rest of the day |

## Room

- Tables of 3–4, everyone able to see the screen
- Four station spaces for Module 03 (tables with the station sheet taped down)
- Flip chart: parking lot, 02 tally, 03 technique chart
- Timer visible to the room

## Running it online

The design works on a video call with these changes:

- Breakout rooms of 3 for group activities; pairs for 2A and stations
- 1B card sort becomes a shared document with a three-colour table
- Stations: every pair gets all four station sheets and chooses; no physical
  rotation, the same 12-minute calls
- Add a 5-minute stretch break at 11:20 and 13:35; take the time from the
  debriefs
- Put every prompt from the deck in the chat so people can copy it
