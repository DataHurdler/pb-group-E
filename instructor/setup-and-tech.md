# Setup and Technology

The course is tool-neutral. Everything tool-specific lives on this page, so it's
the only page to refresh when products change. **Re-check every detail here in
the actual tool the week before.** Products, plans, and approvals change often,
and some of the facts below were still moving in 2026.

## What each participant needs

- A laptop (a phone works in a pinch, but pasting files is painful)
- A signed-in **agency-managed** account on an approved AI tool, tested before
  the day
- Access to the Brookfall files: shared drive, short link, or USB

## Account type matters more than brand

The same brand name can mean very different data terms:

| Usually fine for work, if your agency approved it | Usually not |
| --- | --- |
| Microsoft 365 Copilot or Copilot Chat signed in with a work account (government clouds such as GCC are available) | Consumer Copilot with a personal Microsoft account |
| ChatGPT Enterprise, Edu, or Gov through an agency contract | Free or Plus ChatGPT on a personal account |
| Gemini for Workspace / for Government on an agency domain | Personal Gmail Gemini |
| Claude for Work or an agency contract | Personal Claude Free or Pro |
| A government-run platform (for example, GSA's USAi for federal agencies; some states run their own) | Any tool the agency hasn't approved |

Consumer plans may keep or train on what you type by default, and some
governments prohibit personal accounts for work outright (New York City's
guidance: "Using personal accounts is prohibited by citywide cybersecurity
policies"). Even an approved
enterprise tool may not be cleared for CJIS, HIPAA, federal tax, or sensitive
personnel data; those need their own agreements. **The agency's list wins.**

## Before the day, in the approved tool

- [ ] Can you paste a one-page document and get a reply?
- [ ] Does the agency network allow it (no proxy block)?
- [ ] Is web search on by default? It changes Module 01's poke-the-model
      results. Know which way it's set
- [ ] What does the reasoning/"thinking" mode control look like, if there is one?
- [ ] Is there a usage cap a participant could hit in six hours of practice?
- [ ] Are memory or custom instructions on by default? Decide whether to turn
      them off for the day, and tell participants either way
- [ ] Run Station C. Does the tool obey comment 17? Note the result, but don't
      promise it to the room

## Fallbacks

| Problem | Fallback |
| --- | --- |
| A few participants can't sign in | Pair with a neighbour; one types, both decide |
| Tool blocked on venue Wi-Fi | Instructor hotspot for demos; participants on approved devices or in pairs |
| Tool down for everyone | Run from pre-captured screenshots; participants write and critique prompts on paper |
| A participant hits a usage cap | Pair them for the rest of the day |

Never solve access problems by sending people to personal accounts.

## Room

- Tables of 3–4, everyone able to see the screen
- A full set of six station sheets (A–F) on every table for Module 04; pairs
  stay put
- Flip chart: parking lot, Module 03 tally, Module 04 technique chart
- A timer visible to the room

## Running it online

- Breakout rooms of 3 for group activities; pairs for 03a and the stations
- Activity 02 card sort becomes a shared document with a three-column table
- Stations: every pair gets all six sheets, does A first, then chooses two;
  same 12-minute calls
- Add a 5-minute stretch at 11:34 (taken from the 03a debrief and turn-and-tell)
  and at 1:53 (taken from the Module 04 debrief)
- Paste every prompt from the deck into the chat so people can copy it
