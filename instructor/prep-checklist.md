# Preparation Checklist

## Three to four weeks out

- [ ] Fill in the host-agency fields at the bottom of [COURSE-BRIEF.md](../COURSE-BRIEF.md)
- [ ] Get the agency's AI use policy and read it. Update
      [safe-to-paste.md](../handouts/safe-to-paste.md) and Module 01 talking
      points B to match it; where it is stricter than the card, the policy wins
- [ ] Confirm the approved tool(s) and **how participants get accounts**. This
      is the biggest risk to the day (assumption A3)
- [ ] Ask the agency's privacy or records officer the two questions
      participants always ask: *Are AI chats public records here?* and *Is
      there a disclosure rule for AI-assisted documents?* Write the answers
      into Module 01
- [ ] Book the room: tables for 3–4, projector, power for every laptop,
      flip chart, Wi-Fi that allows the approved tool

## Two weeks out

- [ ] Send the [pre-course email](../participants/pre-course-email.md)
- [ ] Run every activity yourself in the approved tool, on the venue's network
      if possible. Note anything the tool does differently from these notes
- [ ] Re-capture the Module 00 hook demo and the Station A–D "plain" results as
      screenshots, as a fallback if the live demo misbehaves
- [ ] Render the deck: `quarto render slides/course-day.qmd`

## One week out

- [ ] Confirm every registrant has signed in at least once. Chase anyone who
      hasn't; arrange pairs for anyone who can't
- [ ] Recruit a helper if more than 20 participants
- [ ] Print (quantities for N participants, G tables):

| Item | Qty |
| --- | --- |
| [craft-cheat-sheet.md](../handouts/craft-cheat-sheet.md), [safe-to-paste.md](../handouts/safe-to-paste.md), [verify-checklist.md](../handouts/verify-checklist.md) | N each, ideally on card stock |
| [prompt-library.md](../handouts/prompt-library.md), [glossary.md](../handouts/glossary.md) | N each |
| Activity sheets 1A, 2A, 2B, 3, 4, 5 | N each |
| [telework-policy.md](../materials/data/telework-policy.md), [flawed-memo.md](../materials/data/flawed-memo.md) | G each |
| 1B cards, cut | G sets |
| Station sheets A–D with their source files, Station D answer card | 1 per station, plus spares |
| [Pre/post check](../assessment/pre-post-check.md) | 2N |
| [Capstone rubric](../assessment/capstone-rubric.md), [feedback form](../assessment/feedback-form.md) | N each |
| Index cards for the Monday plan | N |

- [ ] Put the Brookfall folder (`materials/data/`) and handouts on a shared
      drive or short link so participants can copy-paste rather than retype

## Day before

- [ ] Run the [run sheet](run-sheet.md) top to bottom
- [ ] Test the deck on the room projector if you can get in
- [ ] Charge everything; pack a power strip and a spare HDMI/USB-C adapter

## Day of, 8:15

- [ ] Projector, deck, and a signed-in tool on the instructor laptop
- [ ] Two clean browser windows ready for the 9:00 weak/CRAFT demo
- [ ] Wi-Fi details on the screen and on table cards
- [ ] Parking-lot sheet on the wall
- [ ] Pre-checks on tables, face down

## Within a week after

- [ ] Send the [follow-up email](../participants/follow-up-email.md) with
      parking-lot answers
- [ ] Score pre/post pairs, summarize feedback, and complete
      [after-action.md](after-action.md)
