# Preparation Checklist

## Three to four weeks out

- [ ] Fill in the host-agency fields at the bottom of [COURSE-BRIEF.md](../COURSE-BRIEF.md)
- [ ] Get the agency's AI use policy and read it. Update
      [safe-to-paste.md](../handouts/safe-to-paste.md) and Module 02's talking
      points to match. Where the policy is stricter, it wins
- [ ] Confirm the approved tool(s), the **account type** (agency-managed, not
      personal), and how participants get accounts. This is the biggest risk to
      the day (assumption A3)
- [ ] Ask the records officer or privacy contact three questions participants
      always ask:
  - Are AI chats records here, and how long are they kept?
  - Is there a disclosure rule for AI-assisted documents?
  - Which data types (CJIS, HIPAA, tax, personnel) is the approved tool cleared for?

  Write the answers into Module 02
- [ ] Book the room: tables for 3–4, projector, power for every laptop, flip
      chart, Wi-Fi that allows the approved tool

## Two weeks out

- [ ] Send the [pre-course email](../participants/pre-course-email.md)
- [ ] Run every activity and station yourself in the approved tool, on the
      venue network if possible. Note where the tool behaves differently from
      these notes: search on by default, refusals, mode names
- [ ] Capture screenshots of the Module 00 demo, Module 01 poke-the-model, and
      the plain version of each station, as a fallback
- [ ] Re-check the vendor guidance links in
      [further-reading.md](../handouts/further-reading.md) and the case links in
      [teaching-cases.md](../handouts/teaching-cases.md)
- [ ] Fill the slide placeholders and render the deck:
      `quarto render slides/course-day.qmd`

## One week out

- [ ] Five days before: confirm every registrant has signed in at least once
      with a work account (the email asks them to by eight days before).
      Arrange pairs for anyone who can't
- [ ] Recruit a helper if more than 20 participants
- [ ] Print (N participants, G tables):

| Item | Qty |
| --- | --- |
| [Cheat sheet](../handouts/prompt-anatomy-cheat-sheet.md), [safe-to-paste](../handouts/safe-to-paste.md), [verify checklist](../handouts/verify-checklist.md) | N each, card stock |
| [Prompt library](../handouts/prompt-library.md), [technique reference](../handouts/technique-reference.md), [glossary](../handouts/glossary.md), [teaching cases](../handouts/teaching-cases.md) | N each (or digital only) |
| Activity sheets 01, 02, 03a, 03b, 05, 06 | N each |
| [telework-policy.md](../materials/data/telework-policy.md) + [flawed-memo.md](../materials/data/flawed-memo.md) | G sets |
| Activity 02 cards, cut | G sets |
| Activity 04 station sheets A–F with their source files | 1 full set per table |
| [Station D answer card](../materials/data/station-d-answer-card.md) | 1 per table, placed face down |
| [Pre/post check](../assessment/pre-post-check.md) | 2N |
| [Capstone rubric](../assessment/capstone-rubric.md), [feedback form](../assessment/feedback-form.md) | N each |
| Index cards | N |

- [ ] Put `materials/data/` and the handouts on a shared drive or short link, so
      participants copy-paste instead of retyping

## Three days before

- [ ] Re-run the Module 00 hook and Module 01 poke-the-model in the approved
      tool. Models change without notice

## Day of, 8:00

- [ ] Projector, deck, and a signed-in tool on the instructor laptop
- [ ] Two clean browser windows ready for the 8:30 demo
- [ ] Wi-Fi details on screen and on table cards
- [ ] A full set of station sheets and a face-down Station D card on every table
- [ ] Parking-lot sheet on the wall; flip chart ready
- [ ] Pre-checks and index cards on tables, face down

## Within a week after

- [ ] Send the [follow-up email](../participants/follow-up-email.md) with
      parking-lot answers
- [ ] Score the paired pre/post checks, summarize feedback, complete
      [after-action.md](after-action.md)

## 30 days after

- [ ] Send the 30-day check-in from the follow-up email
