# Practice materials: the City of Brookfall

Everything in this folder is **fictional** and safe to paste into any AI tool.
The City of Brookfall, its departments, staff, and residents do not exist. Phone
numbers use the reserved 555-01xx range.

Participants use these files all day so that no real agency data enters a prompt
during class. Give them the folder, or print the one-page files, before Module 01.

| File | Used in | What it is |
| --- | --- | --- |
| [telework-policy.md](telework-policy.md) | 01 (1A), 03 (Ground it) | A one-page city telework policy, the "source of truth" |
| [flawed-memo.md](flawed-memo.md) | 01 (1A) | An AI-written summary of that policy with planted errors |
| [park-comments.md](park-comments.md) | 03 (Break it down), 04 | 16 public comments on a proposed dog park |
| [hydrant-notice.md](hydrant-notice.md) | 02 (2A) | A dense legal notice to rewrite in plain language |
| [constituent-emails.md](constituent-emails.md) | 03 (Show it) | Two past replies in house style, and a new email to answer |
| [meeting-notes.md](meeting-notes.md) | 02 (2A) | Messy staff-meeting notes to turn into action items |
| [job-posting-notes.md](job-posting-notes.md) | 03 (Let it ask) | A hiring manager's incomplete notes for a job posting |

Answer keys are in [../../instructor/answer-keys.md](../../instructor/answer-keys.md).
Don't hand those out.

Every file is under one page so that it pastes cleanly into free-tier tools,
which can cut off long pastes.
