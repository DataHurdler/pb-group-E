# Practice materials: the City of Brookfall

Everything in this folder is **fictional** and safe to paste into your approved
AI tool.
The City of Brookfall, its departments, staff, and residents do not exist. Phone
numbers use the reserved 555-01xx range.

Participants use these files all day so that no real agency data enters a prompt
during class. Give them the folder, or print the one-page files, before Module 01.

| File | Used in | What it is |
| --- | --- | --- |
| [telework-policy.md](telework-policy.md) | 01, 03 (Activity 03a), 04 (A: Ground it) | A one-page city telework policy, the "source of truth" |
| [flawed-memo.md](flawed-memo.md) | 01 (Activity 01, Demo D) | An AI-written summary of that policy with planted errors |
| [park-comments.md](park-comments.md) | 02, 04 (C: Break it down), 05 | 17 public comments on a proposed dog park; one contains a planted prompt injection |
| [hydrant-notice.md](hydrant-notice.md) | 00, 03 | A dense legal notice to rewrite in plain language |
| [constituent-emails.md](constituent-emails.md) | 04 (B: Show one example) | Two past replies in house style, and a new email to answer |
| [meeting-notes.md](meeting-notes.md) | 03 (Activity 03a), 04 (E: Give it a form) | Messy staff-meeting notes to turn into action items |
| [job-posting-notes.md](job-posting-notes.md) | 04 (D: Let it ask) | A hiring manager's incomplete notes for a job posting |
| [rollout-plan.md](rollout-plan.md) | 04 (F: Get the other side) | A draft plan to stress-test |
| [station-d-answer-card.md](station-d-answer-card.md) | 04 (D) | Answers to the AI's questions; print and place face down |

Answer keys are in [../../instructor/answer-keys.md](../../instructor/answer-keys.md).
Don't hand those out.

Comment 17 in the park comments contains an instruction aimed at AI tools. It
is a **safe, deliberate demonstration of prompt injection**: text inside a
document that tries to act as an instruction. Don't remove it.

Every file is under one page, so it pastes cleanly; long pastes can be cut
off or skimmed. In Brookfall, Parks and Recreation is a division of Public
Works, which is why the same staff appear across files.
