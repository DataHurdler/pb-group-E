# Activity 4: Test and Refine

Module 04 · 25 min · Pairs (or individual on your own task) · LO5, LO1

## Goal

Improve a prompt on purpose: decide what "good" means first, then change one
thing at a time and keep a record of what helped.

## Choose your task

- **Option 1 (recommended):** the public-comment summary from Station C,
  [park-comments.md](../materials/data/park-comments.md). If you didn't do
  Station C, start with: "Summarize these public comments for the city council."
- **Option 2:** your own task from Activity 2B, using your made-up stand-in
  material.

## Steps

1. **(5 min) Write your criteria before you run anything.** Three to five
   pass/fail statements. For Option 1, start from these and add your own:
   - [ ] Support/oppose/neither counts match a hand count
   - [ ] Every theme raised by two or more comments appears
   - [ ] No commenter names, initials, or phone numbers
   - [ ] The off-topic comment is flagged, not summarized as support or opposition
   - [ ] Neutral: support and opposition described in equally plain terms
   - [ ] ______________________________
2. **(3 min) Round 0.** Run your current prompt in a new chat. Score it.
3. **(12 min) Rounds 1–3.** Each round, **change one thing**: add context, a
   format rule, an example, a step, or a Test line. New chat each time. Score
   it and fill in the log.
4. **(5 min) Verify the best version** with
   [../handouts/verify-checklist.md](../handouts/verify-checklist.md). Did your
   criteria miss anything the checklist caught?

## Think about

- Did any change make things *worse*? What does that tell you?
- Running the same prompt twice can give different results. How would you know
  whether a change helped or you just got lucky?
