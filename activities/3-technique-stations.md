# Activity 3: Technique Stations

Module 03 · 36 min (3 stations × 12 min) · Pairs · LO4

## Goal

Try four techniques on four realistic tasks, and work out which technique fits
which kind of problem.

## How it works

- Do **Station A**, plus **two** of B, C, D. Twelve minutes each; the instructor
  calls time.
- Every station: run the plain version first, then the technique version, in
  **separate new chats**, so you can see the difference.
- At each station, write one line on the station sheet: *"This technique helps
  when…"*

---

## Station A: Ground it (required)

**Task:** Write an employee FAQ for the new telework policy.
**File:** [telework-policy.md](../materials/data/telework-policy.md)

1. **Plain:** Without pasting anything, ask: "Can city employees get reimbursed
   for home internet when they telework? Can they telework from another state?"
   Note the answer.
2. **Grounded:** In a new chat:
   > Using only the policy between the `<policy>` tags, write an FAQ of 6
   > questions employees will ask, with short answers. After each answer, give
   > the section number. If the policy doesn't answer a question, write "The
   > policy doesn't say — contact HR."
   > `<policy>` …paste… `</policy>`
3. **Test it:** Ask in the same chat: "Is there a dress code for video calls
   while teleworking?" It should say the policy doesn't cover it. Does it?

**Notice:** what did the plain version say about internet reimbursement?

## Station B: Show it

**Task:** Reply to Dana Ortiz's email about a pothole and a damaged tire.
**File:** [constituent-emails.md](../materials/data/constituent-emails.md)

1. **Plain:** Paste only Dana's email and ask "Write a reply from Public Works."
2. **With examples:** In a new chat, paste the facts, the two past replies, and
   the new email:
   > Draft a reply to the new email in the same style as the two examples. Use
   > only the facts listed. Don't say whether the claim will be paid.
3. **Check both:** Did either promise to pay? Mention Form RM-2 and the 60-day
   deadline? Sound like the examples?

**Notice:** what did the examples teach that would be hard to describe in words?

## Station C: Break it down

**Task:** Summarize 16 public comments for the city council.
**File:** [park-comments.md](../materials/data/park-comments.md)

1. **Plain:** "Summarize these public comments for the city council." Note any
   numbers it gives.
2. **In steps,** in a new chat, one turn at a time:
   - "List each distinct theme in these comments, and the comment numbers that
     raise it. Mark any comment that's off-topic."
   - Check that list against the comments yourself. Correct it if needed.
   - "Now count how many comments support, oppose, or neither."
   - "Now write a neutral one-page summary memo for the council using that
     list. Don't name or quote individual commenters."
3. **Check:** Compare the counts in both versions with your own count. Did the
   plain version include the phone number from comment 9?

**Notice:** where in the steps did you catch something the AI got wrong?

## Station D: Let it ask

**Task:** Write a job posting for a Parks admin specialist.
**File:** [job-posting-notes.md](../materials/data/job-posting-notes.md)

1. **Plain:** "Write a job posting from these notes." Note anything it made up.
2. **Let it ask:** In a new chat:
   > I need to write a job posting from the notes below. Before you write
   > anything, ask me up to five questions whose answers would most improve it.
   > Ask them all at once, then wait.

   Answer using the station card (salary $42,500–$51,000; closes November 7;
   apply at brookfall.example/jobs; bilingual Spanish preferred, not required;
   one evening meeting a month). Make up anything else.
3. **Check:** What did the plain version invent, such as salary, benefits, or
   requirements?

**Notice:** what did it ask that you wouldn't have thought to include?

---

**You're done when** you've written a "This technique helps when…" line for
each station you visited.
