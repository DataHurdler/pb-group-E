# Activity 06: Capstone, Your Reusable Prompt

Module 06 · 32 min · Individual, then pairs · LO5 (LO2–LO4, SU)

## Goal

Turn the prompt you've been building since this morning into a template that you, or
a colleague, can reuse next month and get a usable first draft, without asking
you anything.

## Requirements

*Before you paste:* stand-in material only, all day.

Your template must have:

1. A **header**: `USE THIS FOR / DON'T USE THIS FOR / CHECK BEFORE USING`.
2. A **before-you-paste** line: what must be removed or replaced first.
3. **The slots** your task needs: Task, Context, Audience, Constraints, Format,
   and an Example if style matters.
4. **At least one technique** from Module 04, chosen because of a failure you
   saw.
5. **`[BRACKETS]`** for everything that changes each time.
6. **A flag line** that makes the AI mark what it assumed or couldn't find.
7. **A before-you-send checklist:** the 2–4 things *you* verify by hand every
   time.

## Steps

1. **(12 min) Build it.** Start from your 03b prompt, your Module 05 log, and
   the [prompt library](../handouts/prompt-library.md). If you used Option 1 in
   Module 05, run your template on two different stand-ins now. Shortcut: in the chat
   where your prompt finally worked, ask *"Turn this conversation into a single
   prompt that would get the final result in one go. Use [BRACKETS] for the
   parts that change."* Then trim it. Run it once with your made-up material.
2. **(11 min) Cold partner test.** Swap templates, **with your stand-in
   material and a one-line test note** (what inputs you ran it on, from Module
   05 or Build). Without any help from the author:
   - Fill in the brackets with made-up details
   - Run it in a new chat
   - **Write down every question you wanted to ask the author**
   - Score it with the [capstone rubric](../assessment/capstone-rubric.md)
   - Tell the author **one thing to keep and one thing to change**
3. **(6 min) Revise.** Every question your partner wrote down is a missing
   bracket or missing context. Fix them and run it again.
4. **(3 min) Save it** where you'll find it on Monday. Use the library-entry
   format: what it's for, the prompt, what good output looks like, where it
   goes wrong.

**You're done when** a partner has run your template without asking you a
question, and you've saved the revised version.

**If you finish early:** run your template on a second, harder stand-in, and
add one line to "where it goes wrong."

## Template skeleton

```
USE THIS FOR: [the task]
DON'T USE THIS FOR: [where it would be wrong or risky]
CHECK BEFORE USING THE OUTPUT: [the facts that must be verified]

BEFORE YOU PASTE: replace [names / account numbers / …] with placeholders.

[TASK: one verb, one job]
[CONTEXT: who I am, the situation, why it matters]
[AUDIENCE: who reads it, what they know, reading level]
[CONSTRAINTS: length, tone, what must stay exactly as written, what's off limits]
[FORMAT: the shape, or a form to fill]
[EXAMPLE, if style matters]
[TECHNIQUE: e.g. "Use only the source. Quote it first. If it isn't there, say so."]
[FLAG: "Mark anything you assumed with [ASSUMED]. List what the source didn't answer."]

<source>
[PASTE, PERSONAL DETAILS REPLACED]
</source>

BEFORE YOU SEND, I CHECK:
- [ ]
- [ ]
- [ ]
```
